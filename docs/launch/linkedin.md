I tested three market legends against 99 years of the S&P 500. None showed a
meaningful difference.

Mercury retrograde, the full moon and eclipses all get blamed for moving markets.
So I measured them the same way: the S&P return over each whole event window,
compared with the nearest non-overlapping window of the same length, using a
2,000-draw permutation test on the daily S&P 500 record (1928–2026). Mercury
retrograde windows average about 22 days; full moon and eclipse windows are 7
days.

Mercury retrograde: +0.48% average over each ~3-week window vs +0.29% over
matched windows. p = 0.62.
Full moon: +0.08% average over each 7-day window vs +0.09% over matched windows.
p = 0.91.
Eclipses: +0.12% average over each 7-day window vs −0.07% over matched windows.
p = 0.25.

All three come back the same way: no meaningful difference in this record. I
publish the misses, not just the hits — the method, the windows and every number
sit on the page.

Descriptive historical research, not advice and not a forecast. The write-up and
the chart: https://strikehike.com/tested
