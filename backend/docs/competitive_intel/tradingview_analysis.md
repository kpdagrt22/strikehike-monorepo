## UI/UX Patterns Observed

### Indicator Detail Pages
- **Chart Thumbnail:** Large, interactive preview showing indicator in action
- **Source Code Tab:** Open-source scripts display full Pine Script code
- **Call to Action:** Prominent "Use on chart" button
- **Social Proof:** Likes ("Boosts"), Comments, Favorites count
- **Documentation:** Best scripts have:
  - Methodology explanation
  - Usage instructions
  - Risk warnings
  - Version history

### Browse Experience
- **Categories:** Trend, Oscillators, Volatility, Volume, Custom strategies
- **Filtering:** By popularity, recency, editor curation
- **Search:** Keyword-based with autocomplete
- **Recommendations:** "Users also viewed" section
