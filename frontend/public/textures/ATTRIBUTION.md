# Texture attribution

Planetary textures are sourced from [Solar System Scope](https://www.solarsystemscope.com/textures/)
and are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- `sun.webp` — Sun photosphere map (derived from `2k_sun.jpg`)
- `earth-day.webp` — Earth day map (derived from `2k_earth_daymap.jpg`)
- `earth-clouds.webp` — Earth cloud map (derived from `2k_earth_clouds.jpg`)
- `earth-normal.webp` — Earth normal map (derived from `2k_earth_normal_map.tif`)
- `earth-specular.webp` — Earth specular map (derived from `2k_earth_specular_map.tif`)
- `moon.webp` — Moon map (derived from `2k_moon.jpg`)
- `jupiter.webp` — Jupiter map (derived from `2k_jupiter.jpg`)
- `saturn.webp` — Saturn map (derived from `2k_saturn.jpg`)
- `saturn-ring.webp` — Saturn ring alpha/color strip (derived from `2k_saturn_ring_alpha.png`)

The source images were resized/compressed to WebP for web delivery. No other
modifications were made.
